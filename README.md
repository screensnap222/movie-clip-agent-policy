# Politique de confidentialité — Movie Clip Agent

Dernière mise à jour : 2026

Cette application est un projet personnel utilisé pour automatiser la
création et la publication de courts clips vidéo sur les réseaux sociaux.

## Données collectées

Cette application n'utilise que les autorisations strictement nécessaires
pour publier du contenu vidéo sur le compte de son propriétaire, via les
API officielles des plateformes concernées (TikTok, Instagram, YouTube).

Aucune donnée personnelle n'est collectée, stockée sur un serveur tiers,
ni partagée ou vendue à des tiers. Les jetons d'accès (tokens) sont
conservés localement, uniquement sur l'appareil du propriétaire.

## Usage

Cette application est à usage strictement personnel et n'est pas
distribuée publiquement.

## Contact

Pour toute question concernant cette politique, contactez le propriétaire
de cette application via son compte GitHub.
